# AegisPay ml-service — fraud scoring.
#
# Pinned exactly, not to a range. A gradient-boosted model is serialised against the
# scikit-learn build that produced it, so an unpinned minor upgrade can change predictions
# or refuse to unpickle at all — and the symptom would be a fraud model that silently scores
# differently after an unrelated rebuild.
#
# The model version recorded on every assessment is a fingerprint of the model's own
# predictions, so a dependency change that alters behaviour shows up as a changed version
# rather than as a mystery.
